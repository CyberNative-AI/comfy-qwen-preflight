Found in the official templates · confirmed in ComfyUI 0.38.0, 2026-09-30

Both Qwen Image 2.1 templates can run the prompt enhancer without its system prompt.

Image Edit ships with the enhancer switched on. Its system prompt node is not connected, and Generate Text’s use_default_template is off, so connecting the node alone still drops the prompt.

Text to Image connects the system prompt, but leaves Generate Text’s use_default_template off. ComfyUI 0.38.0 passes system_prompt only when that setting is on, so the prompt is dropped. The enhancer is off by default, so this starts when you switch it on.

We checked what reaches the enhancer: no system prompt, in either template. It still writes a prompt, but a different one. In our Text to Image test it came out 22–39% shorter.

Fix Image Edit: connect the system prompt node to system_prompt and turn use_default_template on.
Text to Image: turn use_default_template on and delete the <|im_start|>system / <|im_end|> wrapper from the text. The check below finds each step.
