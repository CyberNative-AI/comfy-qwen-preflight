    Notes

      Checked and fine

        Found in the official templates · package 0.11.70 · ComfyUI 0.38.0

        In templates package 0.11.70, both Qwen Image 2.1 templates can run the prompt enhancer without its system prompt.

        Status Fix released in templates package 0.11.73. Both templates in 0.11.73 (checked 2026-10-01) and 0.11.76 (checked 2026-10-03) contain the September 30 system-prompt fix and get no system-prompt flag here when freshly opened.

        ComfyUI 0.38.0 installs templates package 0.11.70; current ComfyUI source pins 0.11.76 (checked 2026-10-03). Updating the package does not change a workflow you saved from 0.11.70: it keeps its old wiring, so check it anyway.

        Fix Image Edit: connect the system prompt node to system_prompt and turn use_default_template on.
        Text to Image: turn use_default_template on and delete the <|im_start|>system / <|im_end|> wrapper from the text. The check above finds each step.

        Evidence: what each 0.11.70 template does, and what we measured

        Image Edit in 0.11.70 has the enhancer switched on. Its system prompt node is not connected, and Generate Text’s use_default_template is off, so connecting the node alone still drops the prompt.

        Text to Image in 0.11.70 connects the system prompt, but leaves Generate Text’s use_default_template off. ComfyUI 0.38.0 passes system_prompt only when that setting is on, so the prompt is dropped. The enhancer is off by default, so this starts when you switch it on.

        We checked what reaches the enhancer in ComfyUI 0.38.0 on 2026-09-30: no system prompt, in either template. It still writes a prompt, but a different one. In our Text to Image test it came out 22–39% shorter.

        Limits

        What a workflow file cannot tell us

        • Launch flags such as --use-sage-attention, which users link to blank images.
        • Your hardware. FP8 weights on Apple Silicon (MPS) are reported to give white images.
        • How ComfyUI moves weights between VRAM, RAM and disk while it runs.
        • Which version of a custom node pack you installed.
        • Image quality, garbled text inside images, or speed.

        We tested it on 17 problems reported in public threads, each rebuilt from the official templates. It catches the 12 that live in the workflow or file names.
